# 恢复后三条路径的五权重性能对比

**预算判定：正式矩阵暂缓，正式样本 0/99。** 本次新增四个完整输出投影验收样本，全部通过。下列实测值均为验收进程首次调用；三次进程中位数、重复调用均值、TTFT、TPOT 和解码吞吐仍待正式测量。

## 本次新增的实测

全输出投影包含 151,936 行，311,164,928 字节。P、D 均为单列激活，分别来自 44-token 预填充末位置和首次单 token 解码。每次进程都读取完整权重，在 CPU 观察到 GPU 消费者完成后结束计时。初始化单列。输出全部 151,936 个 F32 值都与对应原生参考逐字节相等。

| 路径 | 输入 | 初始化，秒 | 首次调用，秒 | 首次结果，秒 | RUN |
|---|---|---:|---:|---:|---|
| symbolic | 预填充 | 7.071 | 306.453 | 313.524 | qual-w5-p-symbolic-001 |
| symbolic | 解码 | 7.267 | 300.954 | 308.220 | qual-w5-d-symbolic-001 |
| cuda | 预填充 | 6.815 | 119.948 | 126.764 | qual-w5-p-cuda-001 |
| cuda | 解码 | 6.632 | 116.708 | 123.340 | qual-w5-d-cuda-001 |

按 symbolic 首次调用时间除以 CUDA 首次调用时间，预填充、解码的观察值分别为 **2.55× 和 2.58×**。两者的初始化都在 6.6 至 7.3 秒，表中首次调用差异主要发生在消费者执行期间。symbolic 对需求范围门控，模拟 75,968 个 4 KiB 页。CUDA B2 在一次完整范围发布前执行 1,187 次分块启动，完成 607,744 个 512 B 请求。各阶段以 N=1 报告，尚不能从这些样本估算进程间波动或把差值单独归因于分块大小。

## 同版正确性简测中记录的首次耗时

每格按预填充 / 解码列出，单位为秒。数据来自 v3-r2-five-001 的 symbolic-002、ptx-003、cuda-002。三个 RUN 的 30 份 summary.json 均已对照原封存清单核验 SHA-256。前四项保留完整张量尺寸，词嵌入按实际输入选行。最后一项三条路径都仅计算原权重末尾 32 行，与上表完整输出投影分别列示。

| 权重 | symbolic，P / D | PTX，P / D | CUDA，P / D |
|---|---:|---:|---:|
| FFN 归一化 | 0.00635 / 0.00612 | 1.88022 / 0.04284 | 0.00643 / 0.00596 |
| Q 投影 | 3.93954 / 3.79448 | 44.19497 / 49.40552 | 1.47128 / 1.43247 |
| FFN 下投影 | 5.85801 / 5.82428 | 67.44786 / 64.15730 | 2.14437 / 2.12104 |
| 词嵌入 | 0.03298 / 0.00355 | 1.15091 / 0.02417 | 0.04652 / 0.00406 |
| 输出投影，末尾 32 行 | 0.06744 / 0.07273 | 0.77344 / 0.77015 | 0.03089 / 0.03350 |

PTX 对解码点积中的每个 half2 发出一个 4 B 请求，并逐输出行启动 R2 点积核。完整 Q 投影、FFN 下投影分别涉及 1,048,576 和 1,572,864 次标量请求。44-token 预填充的 Q 和下投影在原有 F16→F32 转换中拦截完整权重的真实读取，随后送入原 cuBLAS。归一化则在逐 token 的乘法核中读取，PTX 在预填充中读取 44 次归一化向量。词嵌入取 44 行或 1 行，初始化开销另计。这些差异能解释不同权重上的耗时趋势，但单次端到端时间无法分解每一种开销的因果贡献。

## 原预算与停止原因

复用原计划的 99 进程矩阵、路线轮换、计时边界和硬预算。正式上限 4 小时 15 分，总上限 7.5 小时，GPU 进程存活合计上限 6.5 小时，CPU 上限 20 CPU·h。单进程上限为普通权重 120 秒、输出投影 900 秒、整模型 1,200 秒。原计划规定预计无法在预算内完成时暂停正式启动。

PTX 的 32 行窗口需要 16,384 个请求。完整投影行数和请求数均扩大 4,748 倍，达到 77,791,232 个请求。按实测行速线性外推，完整 P / D 首次调用分别约 61.2 / 60.9 分钟。完整 Q 解码也使用相同 1024 列 R2 点积，按其实测行速外推一次完整输出投影约 61.1 分钟。上述两种外推只用于预算评估，尚无完整 PTX 输出投影测量。逐权重正式部分需要 12 次完整 PTX 输出投影，整模型正式部分另需 12 次。仅这 24 次约占 24.4 小时。Q 与下投影按首次加五次重复的原规范也预计突破普通权重进程上限。

若先用各权重的首次实测作为重复代理、整模型按一次 P 和三次 D 加总、只有 PTX 输出投影按行外推，得到下列预算情景。

| 路径 | 逐权重正式调用，小时 | 整模型中所选算子的调用，小时 |
|---|---:|---:|
| symbolic | 1.11 | 1.04 |
| ptx | 13.36 | 12.58 |
| cuda | 0.43 | 0.40 |

合计约 **28.9 小时**，尚需计入初始化、其余模型计算、注册、系统波动和报告核验。重复开销可能异于首次。这是运行预算情景，不是已测生成耗时。若保留全部矩阵，建议正式预留 40 小时、全过程 60 小时，并相应调整各阶段、GPU、CPU 和单进程预算。所有实现内的协议超时和验收条件仍按原定义。
