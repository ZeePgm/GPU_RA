## 接入实现

- symbolic 保留第二次 F 实验的主机范围门控。矩阵按整个需求范围发起访问，嵌入按实际 token 行门控。
- PTX 的归一化乘法使用原 R2 核。解码投影用原 R2 点积核逐行计算，真实的 half2 读取各触发一个 4 字节请求。嵌入核直接生成 F32 行。对于 44-token 的 Q 和 FFN 下投影，ggml 原有的 F32 cuBLAS 路径需要先转换 F16 权重，拦截点位于这次转换的真实加载，转换结果直接送入原 SGEMM。逻辑地址、每次加载的唯一性和完成数均在线检查。
- CUDA 保留 B2 的 256 KiB 分块、32 KiB 窗口和 512 B 请求。每个完整需求范围完成后发布一次。
- 当前逐位验收对应上述两种工作负载形状。对于投影输入列数在 2 至 16 之间的其他批形，PTX 使用逐 token R2 点积，尚未与这些批形的原生内核逐位对照。
