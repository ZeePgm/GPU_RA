# Five representative weights on the restored routes

Use the v3 five_model selection inventory or five_weight with one captured consumer. Set HBFLAB_SAMPLED_ROUTE to symbolic, ptx or cuda for the model. The component executable takes the route as its fifth argument after the executable name.

Symbolic uses the second F host gate. CUDA uses the B2 window and one publication per range. For PTX the original R2 multiply handles the norm. The original R2 down-row arithmetic kernel computes individual output rows of the three projections using the real row pointer and activation. GET_ROWS converts only the requested F16 rows to its F32 destination, in token order. For the wide 44-token Q and down prefill, ggml invokes F32 cuBLAS. The R2 interceptor replaces the F16-to-F32 conversion in that native branch, with the same temporary allocation and SGEMM. The conversion and gathers issue one scalar request per half2. No additional weight copy or request replay precedes the native consumer. Exact address coverage is checked at each launch before discarding its request records.

The correctness run uses the frozen 44-token prefill and single-token decode captures. Each of the three routes runs each consumer once in both phases. Norm, Q, down and embedding retain full tensor dimensions. The output projection checks the final 32 complete rows (151904–151935), at the original GGUF and logical offsets. Only the test fixture applies this window. Comparisons are byte-for-byte with the corresponding frozen native output bytes. The complete 151936-row output projection is supported by the same row loop but is outside the smoke budget. Smaller multi-token shapes (2–16 projection input columns) also use the R2 dot kernel; the bytewise claims apply only to the tested workload shapes.

A separate 44-token, single-output model check jointly selects the first four weights and compares all logits, the KV snapshot, positions and sequence release against native. The full first logit vector is also checked against the archived four-output run. No throughput measurements or timing conclusions are part of this experiment.
